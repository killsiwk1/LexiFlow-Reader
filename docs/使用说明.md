# 使用 LexiFlow

## 从一篇文章开始

打开「首页 → 导入文章」，选择本机 TXT、Markdown、EPUB、PDF 或 DOCX 文件（DOCX 适用于安装版）。导入后可移动原始文件。单文件上限为 50 MiB。TXT 与 Markdown 支持 UTF-8 和带 BOM 的 UTF-16。若提示编码错误，请用文本编辑器另存为 UTF-8。

在「阅读室」打开文章。TXT、Markdown 和 EPUB 底部可翻页，也可输入页码后按 Enter。滚动时自动记录当前段落。右上角的排版按钮可调整字号、行间距、字体或定位本页段落。沉浸阅读按钮隐藏工作区界面，桌面可用 Esc 退出。

## 阅读 Word 文档

在 Mac、Windows 或 Android 安装版中，从首页或书架的「导入文章」选择本机的 .docx。Word 视图使用文档内的格式，支持段落样式、列表、表格、内嵌图片和显式分页。可以点词查义、选句收藏，并从上次的页和滚动位置继续阅读。离线备份包含文档原件。

此版本支持普通、未加密的 .docx。对于旧式 .doc，先在 Word 中另存为 .docx。缺少原字体、复杂浮动对象、自动分页和域可能与 Word 桌面排版有差异。

## 阅读 EPUB 和 PDF

EPUB 首次导入会在本机解析章节、目录、正文和书内插图。「目录」支持跳到章内有目标标识的位置，「上一章」「下一章」按书脊顺序切换。长章节分为单栏阅读页，翻页和段落位置会自动保存。以文字阅读为主的 EPUB 效果最佳。复杂表格、出版商字体、脚本、音视频与固定版式的排版可能简化，带 DRM 的书籍请使用合法取得的无保护副本。

PDF 会将原文件存入本地书架。使用页码框翻页或跳页，在顶部工具栏选择「适合宽度」横向铺满，或「适合整页」一次看完整页，也可按比例放大；放大后可在页面内横向移动。原文件包含书签时，顶部显示「目录」。在搜索框输入词句并确认，结果按页列出。页面有文字层时可点词、拖选文字和通过系统菜单复制。扫描件和缺少可提取文字的页面会给出提示。此版本不含 OCR 或 PDF 解密。

## 阅读主题和句子收藏

「阅读排版」和「设置 → 外观与阅读」共享此设备的全局主题，切换后首页、书架、生词本、统计、设置和弹窗同步生效。选择「跟随系统」可随设备明暗模式切换。米黄色使用暖纸色和棕灰文字，纯白和深色可随时切换。TXT、Markdown 和 EPUB 支持阅读宽度、字体、字号、行距与段落间距。PDF 拥有独立文档视图，支持缩放和主题；查看照片或图表时可开启「原页颜色」。沉浸阅读可扩大当前阅读区域。

选中正文中的英文句子，点击「收藏所选句子」。在阅读页的书签菜单中打开「收藏句子」，可回到相应页或移除摘录。「阅读室 → 收藏句子」可以查阅所有书籍的摘录。删除书籍后，已收藏的句子和来源标题仍然保留。单个摘录最多 8,000 个字符。

## 在语境中学词

点击英文单词，或用 Tab 聚焦后按 Enter。窗口首先显示本地词典释义、可用音标及词性。可展开英文释义，查看词形、词频和文章原句。未收录的词可保留语境后自行补充释义。

「收藏生词」将词条和来源段落加入生词本。同词再次出现时可关联新文章。阅读器的书签图标列出本文标记。取消标记会移除对应词形的高亮，生词本可继续保留该词和学习历史。

「生词本」支持搜索英文或中文释义、熟悉度筛选、按收藏时间或字母排序。点击词条编辑释义、例句和熟悉度。多项释义可分行填写。「导出 CSV」导出当前筛选结果。设置中的 CSV 导出涵盖所有词条。

## 复习和记录

在「复习」选择到期词或自由复习。先回想意思，再显示释义并选 Again、Hard、Good 或 Easy。Again 约十分钟后再次到期。初次 Hard、Good、Easy 分别为一、二、四天。跳过不会更改到期时间。离开后可回到同一轮，历史中可查看下次复习时间。

「学习统计」按日、自然周（周一开始）或自然月汇总。阅读时间按前台阅读器计时，切换窗口、打开查词弹窗会暂停。长时间没有交互时暂停计时。突发退出可能损失最后一个五秒采样周期。设置中可以隐藏首页的个别统计项目。

## 迁移与恢复

在「设置 → 备份与恢复」导出 JSON，保存在自己选择的位置。原生桌面版会记住上次导出目录。将 JSON 复制到另一台设备，在设置里选择「从 JSON 恢复」。核对日期、文章数和词条数后，再确认替换本机数据。取消确认会保留现有数据。建议替换前先导出当前资料。

1.1 的 JSON 含正文、书内插图、PDF 文件、收藏句子、设置、词汇、进度和复习历史。带图书籍的备份较大，导出和恢复需留足内存和存储空间。CSV 适合查阅词汇。第三方词典包单独安装，迁移时请一并保留对应文件。在设置中可重新切回内置 ECDICT。删除文章时可以保留收藏。选择连同生词删除时，仍关联其他文章的词条会保留。

学习数据保存在设备当前用户的应用数据目录。清除应用数据、浏览器站点数据或卸载移动应用可能移除学习记录。导出的备份是可跨设备保留的副本。
