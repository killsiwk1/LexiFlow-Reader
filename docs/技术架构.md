# 技术架构与目录

React 和 TypeScript 提供共享界面，Vite 生成本地静态资源，Tauri 2 将资源打包到原生应用。桌面调用 WKWebView 或 WebView2，Android 调用系统 WebView。学习流程没有服务器、账户、在线查词、遥测或远程字体依赖。

| 目录 | 职责 |
|---|---|
| src/App.tsx、ui.tsx、style.css | 页面导航、响应式布局、主题、对话框和导入控件 |
| src/features/Reader.tsx | 本地文件书架、分页、进度、活动计时和查词窗口 |
| src/features/Vocabulary.tsx、Review.tsx | 词条编辑、复习队列和历史 |
| src/features/Overview.tsx、Settings.tsx | 首页、时间统计和数据管理 |
| src/data/schema.ts、db.ts | 类型、校验规则、Dexie 表及数据库版本 |
| src/data/books.ts、words.ts、backup.ts | 文件解析、词条关联、排期、备份校验与事务 |
| src/data/dictionary*.ts、lookup.worker.ts | 替换词典包、完整性校验和 SQLite 查询 |
| public/dictionary、public/licenses | 内置 SQLite 压缩分片、版本清单和第三方声明 |

| packaging、scripts、tests | 安装程序脚本、词典重建和回归测试 |

## 个人数据库

LexiFlow-Library 使用 IndexedDB 和 Dexie。books 保存文件名、标题、格式、页码和段落号。pages 以文章 ID 与页码联合定位正文，单页最多 80 个段落且目标不超过 6,800 字符，单段最多 3,200 字符。删除正文、元数据和可选的来源词汇在同一事务中完成。导入后保存可读正文，原始文件继续由用户管理。

words 使用规范化单词作主键。来源包含文章标识、标题、原段落与标记词形。reviews 单独追加评分历史。sessions 记录前台时间片，统计按本地时间界限裁剪。settings 存放用户偏好。数据库 v2 在 v1 上增加 practice 表保存本轮复习，不清空旧表。评分、到期日、复习历史和队列前移在一次事务中提交，过期评分提交会被拒绝。

恢复先检查格式、字段、重复键、正文页完整性、阅读位置和复习外键。用户确认后才在一项事务内替换数据。解析或写入失败会保留原数据。支持迁入 v1 和 v2 备份。

## 本地词典

构建时按词首三个小写字符计算分片，将 CSV 全字段写入 128 个 SQLite 数据库，建立大小写不敏感的单词及反向词形索引。首次查词启动本地 Worker，校验所需分片 SHA-256 并加载 SQL.js 的本地 WASM。最多保留三个 SQLite 连接。查询顺序为精确词、词形索引、经过实际查库的词尾还原、基于编辑距离的候选。拼写提示和真实命中分别显示。

内置数据库随应用提供。替换词典通过 LFD1 容器导入，含格式标记、清单长度、JSON 清单及压缩分片。校验通过后将文件提交到独立的 LexiFlow-Dictionaries 数据库。个人释义和历史是保存时的快照，后续替换词典不会改写。

## 平台构建

macOS 使用 Apple 系统 WebKit。桌面开发在 Intel Mac 上使用 Rust 1.94、Tauri 2 和 Apple 命令行工具。项目采用固定应用标识 app.lexiflow.reader，覆盖应用文件时数据库仍由当前用户的 WebView 数据目录管理。

Windows 原生构建默认选择 NSIS 并打入离线 WebView2 安装器。本次 Mac 交叉构建走 x86_64-pc-windows-gnu 和 LLVM MinGW。Rust GNU 目标需要 GCC 命名的运行时链接库，此工具目录分别用 LLVM libunwind 和 compiler-rt builtins 提供。GNU 构建需从匹配的 webview2-com-sys 版本携带 x64 WebView2Loader.dll。定制安装脚本位于 packaging/windows.nsi，按当前用户安装，创建开始菜单入口并登记卸载。安装器随包携带微软官方 x64 Evergreen Standalone Installer，仅在检测到缺失时运行。

Android 使用 Tauri 生成的 Kotlin/Gradle 工程。按 ABI 构建可避免在同一个安装包中重复包含多份本地代码和词典。系统文档选择器负责文件导入导出，系统返回键可关闭对话框或返回前一个页面。应用配置关闭 Android 系统应用数据备份。签名私钥不打包到应用或源码压缩包。

## 1.1 阅读扩展

数据库 v3 仅追加 resources 和 sentences 两张表。新版与 1.0 共用应用标识和 IndexedDB 名称。资源按书籍与名称索引；PDF 使用 1 MiB 二进制分块的 Base64 编码，便于与正文、词条和元数据一同备份。恢复过程在一次事务内执行。书籍删除时同步清理其资源，句子摘录保留来源信息。

EPUB 使用现有 fflate 0.8.2 解包，通过 XML DOM 解析 container、OPF、spine、EPUB 3 nav 和 EPUB 2 NCX。导入阶段将结构转换为阅读块，并将目录锚点转换为本地页号和段落号。书内位图作为本地资源保存。正文使用 React 文本节点渲染，排除书中的脚本和外链资源。压缩文件上限 50 MiB，展开后上限 160 MiB，单资源上限 16 MiB。

PDF 使用 Mozilla PDF.js 4.10.38 的 legacy 模块、同版本 Worker、字符映射和标准字体，全部随软件分发。构建步骤 scripts/prepare-pdf.mjs 从锁定依赖在 public/pdf-engine 中准备资源并复制许可。单页按当前宽度、缩放和像素密度渲染，切页时取消旧任务。文字层负责选择、点词与复制，PDF 书签由原文件目的地映射到页码。全文搜索按需逐页提取文字。

Reader 统一管理翻页、全屏、离线查词、生词收藏和有效阅读时间。PageText 负责可重排文字格式，PdfPage 保留 PDF 原版面。SelectionActions 与 Sentences 共用选区和句子数据库。阅读主题独立于工作区主题，通过保存于本机的偏好驱动 CSS 变量。完整书籍和书内资源均留在本机。
