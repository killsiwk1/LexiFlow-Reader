## 重建

使用 Python 3.11 或更高版本，在项目根目录执行：

```sh
python3 scripts/build_dictionary.py stardict.csv public/dictionary ECDICT.lexdict --version 39cfb9672c0906b63569e0453c2e6abfb9ab182a
```

构建脚本会创建 NOCASE 索引，并对每个数据库执行 SQLite quick_check。独立词典包可用于重新安装或替换。初次使用内置词典无需额外操作。
